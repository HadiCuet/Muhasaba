Muhasaba 1.4.0 — new strings for review

22 strings added for the rebuilt challenge form and the number-keyboard OK bar. These have had one self-review pass for literalness — 32 strings were rewritten, mostly because an English preposition-final label (“Spread over”) had been calqued into a dangling preposition. They still have not been seen by a native speaker, which is what this page is for.

Two rules: keep every {placeholder} exactly as written (they are substituted at runtime), and keep plural forms valid for the language.

Highlighted rows are ones I am still unsure of. Locales marked store language also appear on the App Store listing, so review those first.
