The whole set is a single continuous artwork per language, cut into ten files. Phones are tilted and centred on a file boundary, so one app view is sliced in half and carries on in the next screenshot. Arabic and Urdu mirror completely — file 01 lands on the right, the phones tilt the other way, and the cut order reverses.

  • Captions are written in each language's own idiom, using the vocabulary the app already ships — Turkish says Hedef, Bengali সংকল্প, Malay Cabaran — not one English line translated nine times.
  • Phone content is captured per language on a real simulator, so an Indonesian shopper sees the Indonesian app.
  • File 09 shows the app in a script the reader does not already have (Arabic for most, Bengali for the Arabic and Urdu listings). A list of language names proves far less than seeing the app actually laid out that way.
  • On iPad the caption sits at the top: a tablet large enough to straddle a cut cannot also clear a bottom caption, so it bleeds off the bottom and keeps its title bar instead.
